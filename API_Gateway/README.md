# Api Gateway
## Зоны ответственности:

### Прием запросов от UI:
Этот сервис служит входной точкой для всех клиентов (будь то веб, мобильное приложение или иное устройство). Он получает HTTP/REST-запросы и отвечает за их первичную обработку.
### Маршрутизация запросов:
На основе URL, HTTP-метода и других параметров запрос перенаправляется в нужный микросервис (User Service, Statistics Service, Posts/Comments Service).

## Границы сервиса:

### Не содержит бизнес-логики:
Не реализует функции регистрации, публикации постов или подсчета статистики — лишь передает запросы дальше.
### Изолирован от данных:
Не хранит данные о пользователях, контенте или статистике, а работает только как маршрутизатор.
### Является фасадом:
Интерфейс взаимодействия между UI и внутренними сервисами, поэтому не знает деталей реализации других микросервисов.
