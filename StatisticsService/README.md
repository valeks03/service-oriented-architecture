# Statistics Service
## Зоны ответственности:

### Сбор событий:
Получает уведомления от API Gateway (или непосредственно от других сервисов) о лайках, просмотрах, комментариях и других действиях пользователей.
### Агрегация и хранение статистики:
Обрабатывает и сохраняет агрегированные данные, позволяющие быстро получать сводную информацию о популярности контента.
### Предоставление статистики:
Выдает данные для аналитики или для отображения статистических метрик в UI.

## Границы сервиса:

### Не работает с регистрацией и контентом:
Не обрабатывает регистрацию пользователей, не управляет контентом (постами/комментариями) — его задача исключительно анализ и подсчет.
### Изолирован от деталей других сервисов:
Получает события через четко определенные интерфейсы (например, через брокер сообщений или REST API) и не имеет прямого доступа к БД пользователей или постов.
