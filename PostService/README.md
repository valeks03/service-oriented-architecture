# Post Service
## Зоны ответственности:

### Управление контентом:
Обеспечивает создание, редактирование, удаление и отображение постов или промокодов. Содержит логику работы с текстом, медиа, статусами публикации.
### Работа с комментариями:
Обрабатывает добавление, редактирование и удаление комментариев, включая поддержку вложенных комментариев (ответы на комментарии).
### Связь с пользователями:
Сохраняет внешний ключ автора (user_id), но не обрабатывает аутентификацию — информация о пользователе получается из сервиса пользователей.

## Границы сервиса:

### Не отвечает за аутентификацию:
Делегирует проверку пользователя сервису пользователей и принимает лишь идентификатор пользователя как ссылку.
### Отделен от подсчета статистики:
Хотя события (например, лайки или просмотры) могут отправляться в сервис статистики, этот сервис не подсчитывает статистику сам по себе.
